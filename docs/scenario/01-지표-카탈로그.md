# 지표 카탈로그

수집 대상 매크로 지표의 사양. **설계서(`00`)의 4.3절 제약을 통과한 것만 여기
등재한다** — 과거 이력이 없거나 수정 이력을 알 수 없는 지표는 검증이 불가능하므로
등재하지 않는다.

## 등재 기준

| 조건 | 이유 |
|---|---|
| **과거 이력 확보 가능** | 없으면 백테스트로 검증할 수 없다 |
| **수정 여부가 명확** | 사후 수정되는 지표를 최종치로 저장하면 look-ahead |
| 일 단위 이하 주기 | 사이클이 일 단위. 월간 지표는 반영 지연이 커 별도 판단 |
| 출처가 안정적 | 상시 가동 중 조용히 끊기면 국면 판단이 멈춘다 |

## 상태 표기

`계획` → `수집중` → `검증가능`(과거 이력 확보 완료) → `사용중`(가설 채택됨)

## 국내

| ID | 이름 | 출처 | 주기 | 수정 | 과거 이력 | 상태 |
|---|---|---|---|---|---|---|
| `KOSPI_CLOSE` | 코스피 지수 종가 | KIS 국내업종기간별시세 | 일 | 없음 | 확인 필요 | 계획 |
| `KOSDAQ_CLOSE` | 코스닥 지수 종가 | KIS 국내업종기간별시세 | 일 | 없음 | 확인 필요 | 계획 |
| `VKOSPI` | 코스피 변동성지수 | 확인 필요 | 일 | 없음 | 확인 필요 | 계획 |
| `USDKRW` | 원/달러 환율 | ECOS(한국은행) 또는 KIS | 일 | 없음 | 있음 | 계획 |
| `KR_BASE_RATE` | 기준금리 | ECOS | 변경시 | 없음 | 있음 | 계획 |

`VKOSPI`가 확보되지 않으면 **코스피 종가에서 실현변동성을 계산해 대체**한다.
파생 지표는 원본 지표만 저장하고 계산은 `core/regime.py`에서 한다 — 계산식을
바꿔도 데이터를 다시 받지 않아도 되고, 백테스트 재현성이 유지된다.

## 해외

| ID | 이름 | 출처 | 주기 | 수정 | 과거 이력 | 상태 |
|---|---|---|---|---|---|---|
| `SOX` | 필라델피아 반도체 지수 | 확인 필요 | 일 | 없음 | 확인 필요 | 계획 |
| `SPX` | S&P 500 | 확인 필요 | 일 | 없음 | 확인 필요 | 계획 |
| `VIX` | 변동성지수 | FRED | 일 | 없음 | 있음 | 계획 |
| `US10Y` | 미국 10년 국채금리 | FRED | 일 | 없음 | 있음 | 계획 |
| `DXY` | 달러 인덱스 | 확인 필요 | 일 | 없음 | 확인 필요 | 계획 |

`SOX`를 우선순위에 둔 이유: 2026-08-19 워치리스트 38종목 중 **절반 이상이
반도체 소부장**이었다. 우리 유니버스에 대한 설명력이 `SPX`보다 높을 가능성이 있다.

## 시차 주의

해외 지표는 **한국 시각 기준으로 언제 알 수 있었는지**가 중요하다. 미국장
종가는 한국 시각 다음날 새벽에 확정되므로, 그날 아침 판단에는 쓸 수 있지만
**전일 판단에 쓰면 look-ahead**다.

`ingested_at`을 한국 시각으로 정직하게 기록하고, 백테스트는 그 값으로
재생한다(`00` 설계서 4.3절). 이 시차를 대충 다루면 백테스트만 좋아진다.

## 미등재 — 검토했으나 뺀 것

| 지표 | 뺀 이유 |
|---|---|
| 외국인/기관 순매수 | 예측지표보다 **동행지표** 성격. 지수 추세와 중복 가능성이 커, 1·2번 가설 검증 후 잔여 설명력이 있을 때만 재검토 |
| 신용스프레드 | 국내는 일 단위 확보가 어렵고, 확보되어도 지수 추세와 강하게 상관 |
| 경기선행지수 | 월간 + 사후 수정. 일 단위 사이클에 반영 지연이 과도 |
| 뉴스 센티먼트 | `00` 설계서 5절 참고 |
